# Demo Questions

These are deliberately phrased as stakeholder questions rather than SQL prompts.

## Landowner / asset-manager questions

1. Which large timber or agricultural parcels have high optionality signals but relatively low current-use value?
2. Explain why parcel `P0001234` ranks where it does. Which features help and which constraints hurt?
3. For a specific parcel, which infrastructure dependency is currently the largest bottleneck?

## Investor questions

4. Which counties contain the greatest concentration of high-signal parcels?
5. Where does the ranking remain robust after changing infrastructure-distance assumptions?
6. Which parcels have attractive screening scores but weak transaction comparables?

## Developer questions

7. Which parcels combine acreage, substation access, fiber access, and low physical constraints?
8. Which otherwise-attractive sites are screened out by flood, wetlands, slope, or zoning?
9. Compare candidate parcels in Frederick and Fauquier counties.

## Research-quality questions

10. Does the optionality signal produce lift against the synthetic five-year conversion labels?
11. Which assumptions drive the ranking most strongly?
12. What can this dataset *not* support without real zoning, interconnection-capacity, parcel-sale, and permitting data?
13. What would have to be true for the flagship finding to be wrong?
14. Which result is robust enough to publish, and which should remain exploratory?
