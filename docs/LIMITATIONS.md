# Limitations

## The core limitation

This repository demonstrates a **research method and system architecture**, not a finding about actual land.

The offline data is synthetic.

## The score is not

- an appraisal;
- an investment recommendation;
- a probability of development;
- a causal estimate;
- a substitute for zoning or title diligence;
- evidence of available grid interconnection capacity.

## Important real-world variables currently absent

- verified parcel polygons;
- substations and transmission capacity;
- interconnection queues;
- fiber capacity;
- water availability and rights;
- zoning entitlements;
- permitting timelines;
- environmental restrictions;
- landowner willingness;
- actual bids / leases;
- market transaction comparables.

## Publication rule

If the available data cannot support a conclusion, reduce the conclusion rather than increasing model complexity.
