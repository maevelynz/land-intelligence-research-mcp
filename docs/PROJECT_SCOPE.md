# Project Scope

## Current scope

The current prototype studies development optionality using synthetic parcel, infrastructure, land-use, and outcome data.

## Supported demonstration claims

The system can demonstrate reproducible parcel screening, county comparison, parcel explanation, synthetic signal separation, and governed LLM access through MCP.

## Claims not supported

The system does not currently support real-world appraisal, NPV / IRR underwriting, entitlement probability, utility-capacity determination, power interconnection feasibility, development-cost estimation, lease valuation, transaction-market forecasting, habitat-quality scoring, biodiversity impact measurement, or causal inference on real development outcomes.
