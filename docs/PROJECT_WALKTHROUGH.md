# Project Walkthrough

Land Intelligence Research MCP is an independent research prototype for evidence-grounded AI analysis of land development optionality.

The core design principle is:

> **The LLM reasons; governed tools compute.**

The language model handles ambiguous questions, research planning, tool selection, synthesis, and stakeholder translation. DuckDB and the MCP tool layer own joins, definitions, screening logic, and validation.

The project demonstrates deterministic relational synthetic data, DuckDB analytics, transparent screening logic, MCP-governed access, parcel and market screening, synthetic signal validation, stakeholder-specific interpretation, and explicit analytical gaps.

It does not claim to be an appraisal, underwriting model, development recommendation engine, predictive model validated on real transactions, habitat-quality model, or substitute for legal, engineering, environmental, or investment diligence.
